# Job Market Analysis Dashboard

## 📌 Project Overview
This project presents an interactive Job Market Analysis Dashboard that analyzes data professional job opportunities across the United States. The dashboard highlights hiring trends, salaries, required skills, top industries, education levels, and geographic distribution.

## 🎯 Objectives
- Analyze job openings across the US.
- Identify top hiring states and industries.
- Compare average salaries by job role.
- Visualize the most in-demand technical skills.
- Provide insights for aspiring data professionals.

## 🛠️ Tools & Technologies
- HTML5
- CSS3
- JavaScript
- Chart.js

## 📊 Dashboard Features
- Total Job Openings
- Average Salary Analysis
- Top Hiring States
- Job Role Distribution
- Industry-wise Hiring
- Skills Analysis
- Education vs Salary

## 📈 Key Insights
- Total Job Openings: **742**
- Average Salary: **$101.5K**
- Highest Demand Role: **Data Scientist**
- Top Hiring State: **California**
- Most In-Demand Skill: **Python**
